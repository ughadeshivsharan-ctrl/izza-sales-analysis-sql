# 🍕 Pizza Sales Analysis (SQL & Python)

A data analysis project exploring pizza sales performance using **Python** and **SQL**. The project identifies top-selling pizzas, revenue trends, popular pizza sizes, order patterns, and category-wise sales performance.

## 📊 Project Summary

This project analyzes pizza sales data to uncover business insights around customer ordering behavior, revenue generation, and product performance — helping understand what sells best, when, and why.

## 🛠 Tools Used

- **Python** (Pandas) — data cleaning & analysis
- **MySQL** — querying and aggregating sales data
- **Jupyter Notebook** — exploratory analysis

## 🗂 Dataset

The dataset consists of four related tables:
- `orders` — order date, time, and ID
- `orders_details` — quantity and pizza ordered per order
- `pizzas` — pizza ID, size, and price
- `pizza_types` — pizza name, category, and ingredients

## 🔍 Key Analysis Performed

- Total number of orders placed
- Total revenue generated from pizza sales
- Highest-priced pizza
- Most common pizza size ordered
- Top 5 most ordered pizza types
- Orders distribution by hour
- Category-wise distribution of pizzas
- Average pizzas ordered per day
- Top 3 pizza types by revenue
- Percentage contribution of each pizza type to total revenue
- Cumulative revenue over time

## 📈 Key Insights

| Metric | Result |
|---|---|
| 📌 Total Orders | 21,350 |
| 💰 Total Revenue | $817,860.05 |
| 🍕 Most Ordered Pizza | The Classic Deluxe Pizza |
| 🏆 Highest Revenue Pizza | The Thai Chicken Pizza |
| 📏 Most Popular Size | Large (L) |
